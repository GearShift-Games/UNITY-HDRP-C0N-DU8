# Documentation du dossier Assets
## Animations
Contient tout les animation clips et animation controllers, incluant des animation 2D et 3D.

## Audio
Contient tout les fichiers audio du projet.

## Barmetler
Dossier d'une extension utilisée pour construire les routes (extension très instable)

## Fonts
Contient toutes les polices de charactères du projet.

## Materials
Contient tout les matériels utilisés sur les modèles 3D.

## Medias
Contient tout les images, tels que les logos et icônes UI, ainsi que les textures pour les modèles 3D

## Models
Contient tout les modèles 3D utilisés dans le projet.

## Prefabs
Contient tout les prefabs utilisés dans le projet Unity.

## Scenes
Contient toutes les scènes Unity, seulement les scènes dans le dossier "FinalScene" sont complètement fonctionnelles, les autres ont été utilisées pour le développement du projet.

## Settings
Un dossier que Unity crée par défaut. Contient les paramètres du projet.

## Shaders
Contient les shaders qui rendent le projet beau.

## TutorialInfo
Un dossier que Unity crée par défaut. Contient des trucs rapport avec le projet dans le pipeline Unity HDRP.

## VFX
Contient les VFX, tel que l'explosion d'élimination.

## extOSC
Le dossier d'extension extOSC qui permet la communication OSC entre les arduinos, TouchDesigner et Unity.

## indoors
Un dossier de paramètres de pipeline Unity HDRP.

## test_road
Contient des modèles 3D et prefabs utilisés durant la production du projet pour tester le système de route Barmetler.
